# 鲸鱼看板（AgentTeam 活体摘要）

> 版本：1.5.0 起。只读展示，不参与 AgentTeam 的任务写操作。

## 目标

把 AgentTeam 的共享任务板变成鱼身上的“活体摘要”：

- 任务板有任务时，鱼头旁常驻一块小看板：`3 个任务：1 个在做，1 个等人接，1 个卡住了`；
- 有子 Agent 等待审批时，鱼冒一次气泡：`有个子 Agent 在等你批东西`；
- 全部完成时，鱼做一次“收工”动作，气泡：`鲸群回巢了`；
- 不需要打开 Harness 的任务板面板。

## 非目标

- 不创建、认领、完成、重开、删除、改派任务；
- 不读取任务 `description` 正文，不把任务内容送模型/TTS；
- 不替换 Harness 的 AgentTeam 面板；
- 不拦截 Harness 的输入、拖放、审批、快捷键。

## 数据源

### 任务板

`@deepseek-ai/dsh-agent-team` 的浏览器投影 `agentTeam`：

```ts
{ enabled: boolean, tasks: TeamTaskView[], failure?: string }
```

`TeamTaskView` 的公开字段：`id / revision / subject / description / status / blockedBy / writeScopes / ownerId? / ownerName? / ready / writeScopeWarnings`。

读取方式：

- 本插件的根组件在 `shell.overlay`（root scope），拿不到 `useProjection`；
- 因此注册一个**会话级探针**到 `conversation.input.overlay`（session list slot），从公开 props 拿 `sessionId / useProjection / useSessionStatus / useSessions`；
- 探针只把 `agentTeam` 投影和同一 Team 根树内的 pending approval 写进模块级 store；
- `client/team-source.ts` 的 `createTeamSource()` 订阅这个 store；不读日志、不轮询、不碰任务服务。

### 审批

任务板 schema 不含审批。审批来自公开的会话 pending interaction：

- `useSessionStatus(...).pendingInteraction`；
- `PendingApproval` 的公开字段 `kind='approval' / key / toolName / sessionId`；
- 只收同一 root 及其 `subagentCatalog` 后代会话的审批；
- `at` 是适配器首次观测时间（公开对象没有创建时间戳），不推测真实请求时间；
- 气泡只显示“有个子 Agent 在等你批东西”，不显示 `reason / toolName`。

## 模块与依赖方向

```text
agentTeam 投影 + pending approval
        ↓
client/team-source.ts        只读适配器（会话级探针 + store）
        ↓ TeamSource
client/team-watch.ts         订阅 → 摘要 → 展示意图
        ↓ TeamSurface（接口）
client/team-surface.ts       唯一同时认识“独立挂件 + 调度器”的适配器
        ├─ client/team-status-bubble.ts  常驻独立挂件（不进调度器）
        └─ bubble-queue 的 team 线路      一次性提醒（走调度器）
```

规则：

- `shared/team-contract.ts`：唯一契约，只放类型；
- `shared/team-board.ts`：纯函数，不碰 DOM/React/DSH；
- `team-source.ts`：只读公开投影/审批，不 import DSH 内部实现；
- `team-watch.ts`：只依赖 `TeamSource` / `TeamSurface` 两个接口；
- `team-surface.ts`：唯一同时认识独立挂件和调度器的文件，只做路由；
- `client.ts`：只做装配，不含看板业务判断。

## 展示规则

### 常驻看板

- 独立 DOM，`pointer-events:none`，不抢点击/焦点，不朗读；
- 有任务就显示，任务清空/Team 关闭才隐藏；
- 位置跟随鱼 stage（100ms 节流），落在鱼头右侧并做视口钳制；
- 文案只显示计数；不显示 `description`。

### 一次性提醒

走 `bubbleScheduler` 新增的通用 `team` 线路：

```text
poem > voice > main > persona > team > tool
```

- 低于主人对话/诗词/persona，不抢它们；
- 审批提醒每个新审批 id 一次；
- 全部完成只在“非 done → done”时提醒一次（首次加载时已经全部完成不补播）；
- 看板错误只提示一次；
- 同 key 10 秒去重；
- 提醒期间常驻看板压暗。

### 文案

```text
3 个任务：1 个在做，1 个等人接，1 个卡住了
2 个任务：1 个在做，1 个等人接
1 个任务：在做
全部完成：鲸群回巢了
审批：有个子 Agent 在等你批东西
错误：看板暂不可用
```

## 开关

菜单：

```text
鲸鱼看板：开 / 关
```

- localStorage：`chubby-team-board = 'on' | 'off'`，缺省开；
- 关闭只影响展示，不影响 Harness 的 AgentTeam；
- Team 未启用、看板空、投影不可用时完全静默（错误只提示一次）。

## 已知限制

1. 任务板没有时间戳：“卡住”第一版只算 `pending && ready === false`（依赖未满足），不做 in_progress 超时判定。
2. 审批 `at` 是首次观测时间，不是真实创建时间。
3. 只跟随当前会话 root 的 Team；多 Team 不聚合。
4. 探针依赖 `conversation.input.overlay` slot；DSH 未来改 composer 结构时可能静默无数据（不报错、不拖垮宠物）。
5. 只读：没有任务写方法、没有 `remote.agentTeams` 写调用。
