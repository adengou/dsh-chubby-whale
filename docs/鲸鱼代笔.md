# 鲸鱼代笔（面板版）

> 一句一落，直接接在正文里；像正常写文档，不像记流水账。

## 怎么用

1. 右键鱼 →「代笔 ▸」→「打开代笔面板」；
2. 点面板上的 🎤（麦克风图标）开始听写，再点一下暂停；
3. 说一句，停一下：这句话会**直接接在正文当前段落末尾**；
4. 正文可以随意改字、删字、改标点；
5. 在正文里按回车，立刻新起一段；
6. 在工具栏的「保存类型」下拉里选 TXT/DOCX，随时点「保存」直接存当前类型；
7. 没有“停止代笔”这个概念；关闭面板或卸载时自动释放临时麦克风。

## 一句一落

- 一句说完（停顿/句末标点）→ 接一句；
- **不换行、不编号、不列表**；
- 中文句间直接接；英文/数字相邻补一个空格；
- 回车 = 段落标志，马上另起一段；
- 动态判断这句有没有说完：短句最多等 900ms，长句 600ms 就收；
- 全程用逗号落句：句号/问号/感叹号/英文句点都改成「，」；已经是逗号则不重复；
- 同一句 1.5 秒内重复识别只收一次；
- 面板最多 2000 句；超出会提示，已有文字不丢。

## 正文

- 正文是**可编辑 textarea**，不是只读列表；
- 主人改过的字不会被下一次语音追加覆盖；
- 语音追加落在最后一段末尾；主人正在中间编辑时不会重排全文；
- 保存时使用正文当前内容，包含主人所有修改和回车段落。

## 保存

- 工具栏有「保存类型」下拉（TXT 文档 / DOCX 文档，默认 DOCX）；点「保存」直接按当前类型保存，不再弹二次选择：
  - **TXT**：原样保存全文，保留换行和空行；
  - **DOCX**：本地生成最小 OOXML，Word/WPS 可打开；每行一个段落，空行保留空段落。
- 保存不需要先“停止”；随时可存；
- 不需要联网，不上传正文。

## 边界

- 这是**面板内代笔**，不向 Word/飞书等第三方窗口自动注入；
- 不自动发送到聊天，不自动保存第三方文档；
- 不录音存档；只在听写期间使用麦克风；
- 语音待命关着时，点 🎤 会临时开麦；暂停/关闭面板会释放；
- 浏览器不支持录音或没有麦克风权限时，面板会给出人话提示。

## 与官方语音输入的区别

官方负责“说话 → 聊天输入框”；  
鲸鱼代笔负责“说话 → 小鲸面板内可编辑正文，可保存 TXT/DOCX”。

两者不冲突，也不互相替代。
