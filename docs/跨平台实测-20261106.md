## 二、Windows 实测过的项

1. **TTS**：`python` / `py -3` 探测；`edge_tts` 合成 mp3（实测 18,288 / 27,072 / 13,392 字节）；worker 启动失败回退单次 spawn；超时 kill（`taskkill /T /F` 兜底路径被调用）；解释器缓存生效。
2. **存储**：4 线程并发 100 次原子写（`done=100 errors=0`）、743 次中间读无撕裂、无 `.tmp` 残留；rename 失败重试 3×20ms；坏文件隔离名（`memory.json.bad-2026-11-06T01-51-52-723Z`）文件名合法。
3. **数据/构建**：`tsc`（host + client 两个配置）、`esbuild`、`selftest`、623 项单测、50 项语音契约、smoke-client/host 各 18 项、`check-*` 检查器全绿。
4. **浏览器端**：Chrome/Edge 实机日常使用（拖拽、菜单、语音、朗读、说书）。
   —— 但 **Safari/Firefox 没有真机跑过**，MediaRecorder mime、`decodeAudioData` 解 mp4、iOS 手势恢复均按规范实现 + stub 验证。

## 三、非 Windows 的验证方式（诚实口径）

- 用 `process.platform` mock 走 POSIX 分支（`chmod 0600/0700`、`fsync`、`SIGTERM kill`）——**代码路径通，但真实文件系统行为未验证**；
- 解释器候选链对 Linux/macOS 是 `python3 → python`——**未在真机确认 python3 与 edge_tts 的存在性**；
- 路径与主目录：全仓 `join` + `homedir()`，无平台分支，逻辑上等价，未在真机跑。

## 四、已知跨平台风险（按严重度）

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| Linux/macOS 上 `python3` 未装 `edge_tts` | TTS 降级为浏览器朗读（不崩） | 探测失败 → 501 → 客户端降级；文档在 `docs/发布规范.md` 说明 |
| POSIX 真实 `rename` 原子性与 NFS/overlayfs | 极端情况下原子写退化 | 失败重试 + 临时文件清理；NFS 场景建议本地盘 |
| Safari `MediaRecorder` 只出 `audio/mp4` | ASR 可能不认 | 已实现 mp4→WAV 转码（`decodeAudioData`），失败回退原字节并标 `webm` |
| Safari `speechSynthesis` 不触发 `onend` | TTS 队列卡死 | 已加看门狗超时收口 |
| iOS 无 `PointerEvent` 或 capture 失效 | 拖拽中断 | 已实现 touch/mouse 双绑定 + window 兜底 |
| FAT/exFAT 的 2 秒 mtime 精度 | 数据热更新偶尔延迟 1–2 秒 | 已知限制，注释说明 |
