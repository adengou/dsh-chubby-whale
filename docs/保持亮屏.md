# 保持亮屏（默认开）

> 默认不息屏；设置里可关。

## 怎么用

右键鱼 →「设置 ▸」→「行为开关 ▸」：

```text
保持亮屏：开   ← 默认
保持亮屏：关
```

- **开**：DSH 页面打开且可见时，申请浏览器标准 Screen Wake Lock，阻止显示器自动休眠；
- **关**：释放锁，按系统电源设置正常息屏。

## 跨平台与实现

用浏览器标准 API：

```js
navigator.wakeLock.request('screen')
```

- 不依赖第三方；
- 不联网；
- 不写系统电源设置；
- DSH 桌面端 / Chromium 浏览器可用；
- Windows / macOS / Linux 同一套代码。

## 边界（重要）

- 只能保持**屏幕**不休眠，不能覆盖合盖、锁屏、系统电源策略；
- 页面最小化、被隐藏、关闭后，浏览器会释放锁，此时不能保证亮屏；
- 不支持 Wake Lock 的环境（部分旧浏览器）会提示“当前环境不支持”，不会假装生效；
- 默认开是为了主人用鱼时屏幕不黑；如果长期挂机，建议手动关掉省电。

## 与系统设置的关系

这是页面级能力，不是系统级电源管理。  
要“合盖也不睡”“锁屏也保持”，只能改操作系统电源设置，插件不越权。
