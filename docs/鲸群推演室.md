# 鲸群推演室（决策参谋）

> v0.1 起。四位视角给证据、假设、分歧与风险提示；最终拍板永远在主人手里。

## 这是什么

「鲸群推演室」把一次重要决定拆成一场结构化的推演会议：

- 鱼是**推演主持**，不是决策者：负责召集成员、整理材料、把分歧和未决问题摆给主人；
- 固定四位成员：**财务、风险/法务、客户代言人、反方**；
- 产出一份六项齐全的决策备忘录（见下文「输出」）；
- 只给方法与风险提示，**不替主人做决定、不自动执行任何动作**。

## 怎么用

1. 在鱼身上点右键，打开菜单；
2. 选「**推演 ▸**」→「**开始推演…**」；
3. 在面板里填写：
   - **决定（必填）**：这次到底要定什么事；
   - 背景与约束（可选）：已知事实、限制、担心，没有就留空；
   - 候选选项（可选）：A / B / C，或「还没想好」；
   - 期限（可选）：什么时候必须拍板；
4. 点「**开始推演**」。鱼会把议题整理成一份「推演简报」写进剪贴板，并冒一句
   「推演议题已复制…」，同时打开聊天面板；
5. **主人自己**把剪贴板内容粘贴到对话里发送（面板不自动发消息）；
6. 鱼收到后按规则召集四位成员，先复述理解、指出还缺什么信息，得到确认后再开会；
7. 想要一份完整的规则文本，可以选「**复制推演规则**」，粘贴给鱼即可按规则办事。

面板是一块**浮动卡片**：拖动标题栏可把它挪到屏幕任意位置，位置在本次打开期间保留；
点右上角「×」、按 Esc 或点「取消」关闭。它不会挡住整页，旁边的内容仍可查看。

点「开始推演」后，面板**不会消失**，而是留在结果态，显示：

- 议题已复制；
- 打开对话、粘贴发送；
- Agent Team 任务前缀：`[FIN] / [RISK] / [CUST] / [OPP] → [MEMO]`；
- 结果显示在 DSH 对话里，鱼脚下显示「推演 3/4」这类进度。

推演过程按 AgentTeam 跑：四张角色任务 + 一张 MEMO 汇总任务，`MEMO` 依赖四个角色任务；
鱼只读任务板显示进度，不自动认领、不自动完成。

复制失败时面板会在按钮上方显示一行内联错误并保持打开，已填内容不会丢；
「复制推演规则」失败时会提示手动打开本文件（`docs/鲸群推演室.md`）。

## 四位视角（固定）

| id | 角色 | 职责 |
| --- | --- | --- |
| `finance` | 财务 | 核算成本、现金流、投入产出与机会成本，给出量级和敏感性区间；只做风险提示。 |
| `risk` | 风险/法务 | 识别合规、合同、责任与下行风险，标出法律与监管的不确定性；只做风险提示。 |
| `customer` | 客户代言人 | 站在用户、客户和受影响方的立场，质疑价值、体验与信任成本；引用证据要标来源。 |
| `contrarian` | 反方 | 专门找反例、失败路径和被忽略的前提，提出能推翻当前结论的证据条件。 |

每位成员都必须：查证据、标假设、给置信度（0–100%）；没有证据就写「未核实」，
禁止编造来源、价格、法条或结论。

## 输出（MEMO 六项齐全）

1. **决策备忘录**：候选选项、评价标准、逐项评分（写清评分依据）；
2. **分歧地图**：谁和谁在哪里分歧，分歧来自事实还是价值判断；
3. **假设账本**：每条假设、依据、置信度，以及假设不成立时会怎样；
4. **最便宜可逆实验**：用最小代价先验证哪个关键假设，如何回滚；
5. **待核实清单**：尚未核实的事实、数据、来源与负责核实的人；
6. **非专业意见声明**：财务与风险/法务只做风险提示，不构成财务意见或法律意见；
   最终决定由主人作出。

## 边界

- **不是专业意见**：财务、风险/法务只做风险提示；涉及真实金额、税务、合规或诉讼时，
  请主人找持证专业人士复核。本功能不提供法律意见、不含真实价格或报价。
- **不自动执行**：不自动下单、付款、签约、发布、发消息或改动真实资产与账号；
  决定要不要做、什么时候做，都由主人自己拍板。
- **不编造来源**：找不到出处就标「未核实」，不虚构文号、价格、法条、专家或案例。
- **不自动改任务板**：任务板的每次变化都必须来自主人在本会话中明确发起推演后，
  对 AgentTeam 工具的显式调用；插件本体不在后台写入任何任务。
- **不自动发消息**：面板只把简报写进剪贴板；发送这一步由主人自己完成。
