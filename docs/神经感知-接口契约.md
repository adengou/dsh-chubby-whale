export interface EventLog {

## 第二层：二维情绪模型 + 表达映射

文件：`src/client/nervous/affect.ts`

```ts
export interface AffectState { arousal: number; valence: number } // 0-100
export interface AffectModel {
  read(): AffectState
  apply(e: NervousEvent): void
  tick(now: number, away: boolean, night: boolean): void
  reset(): void
}
export function createAffectModel(opts?: { initial?: AffectState }): AffectModel
export function faceOf(s: AffectState, night: boolean): Mood
```

情绪规则（写死在实现里，集中成常量便于调参）：
- `activity`：arousal +2，valence +1
- `back`：arousal +2，valence +3
- `work`：arousal +2，valence +1
- `away` 心跳：arousal -1，valence -1
- 夜间心跳：arousal 压到 ≤40
- 全部夹在 0–100

表情映射（九格，返回 `Mood`：`idle|hungry|sleepy|excited|shy|sulk|guard`）：
- 夜间 或 arousal ≤20 → `sleepy`
- valence ≤20 且 arousal ≥60 → `sulk`
- arousal ≥85 且 valence ≥60 → `excited`
- valence ≥80 且 arousal ≤40 → `shy`
- 其余 `idle`

## 第三层：宿主事件源

文件（三处，互不重叠）：
- `src/host/nervous/collector.ts`：宿主侧**只读**收集器
- `src/host/routes/nervous.ts`：`GET /api/chubby-whale/nervous`
- `src/client/nervous/host-sense.ts`：客户端轮询源

```ts
export interface SenseSource {
  name: string
  start(onEvent: (e: NervousEvent) => void): void
  stop(): void
}
export function createHostSense(opts?: { intervalMs?: number }): SenseSource
```

收集器要求：订阅 dsh 可用的会话事件（先研究 `node_modules/@deepseek-ai/*` 的类型与其他插件的用法），环形缓冲 200 条；尽量只读、失败隔离。**找不到可靠事件名时**退化为“路由返回可用信号集合”，并在交付报告里如实说明，不许编事件名。

客户端要求：轮询间隔默认 3000ms；页面隐藏时暂停；失败静默；只把新事件回调出去（按 `at` 去重）。
