# 重启后预案（dsh web 重启 ← 本次迭代之后）

> 用途：主人重启 dsh web 后，如果某个功能不对，按本文顺序排查，**不要先怀疑代码**——今天多数"没生效"都是安装副本/未重启/缓存问题。
> 原则：先看日志与接口（只读），再动手。

## 一、插件根本没起来

按顺序查：

1. **日志里有没有 `[chubby-whale]` 开头的行**（没有 = 插件没加载）。
2. **package.json 有没有 BOM**：`node scripts/check-bom.mjs`（带 BOM 会让 DSH 静默跳过整个插件）。
3. **安装副本完整性**：`node tools/check-installed.mjs`（今天踩过"安装副本漏 `dist/shared/immutable.js`"——坑 34）。
   **注意**：该工具只适用于"复制式安装"；本项目当前是 **link 安装**（`~/.dsh/plugins/dsh-chubby-whale` 直接指向源目录），此时它会报「找不到安装副本」，属正常，不是故障。
4. **dist 是否完整**：`node --check dist/index.js`、`node --check dist/client.js`（语法错会加载失败）。
5. 以上都过还没起来：把 `~/.dsh/plugins/dsh-chubby-whale` 与安装副本整树同步一次（不要只挑文件），再重启。

## 二、起来了但某个接口不对

先统一用只读接口确认，再看代码：

```powershell
# 1) 插件在线
Invoke-RestMethod http://127.0.0.1:3080/api/chubby-whale/status
# 2) 自检面板数据
Invoke-RestMethod http://127.0.0.1:3080/api/chubby-whale/stats
# 3) 只读配置（不应含任何 Key 内容）
Invoke-RestMethod http://127.0.0.1:3080/api/chubby-whale/config
```

| 症状 | 查什么 | 常见原因 |
| --- | --- | --- |
| `/stats` 没有 `tts`/`backup` 字段 | 重启后是否加载新代码 | 旧模块还在（未重启/热重载） |
| `/config` 404 | 路由表是否含 `config` | 同上 |
| 说书进度变空 | 日志有无 `STORY-PROGRESS-MIGRATED` | 迁移未跑（首启会跑一次） |
| `/fishfood` 还是旧值 | `/fishfood` 的 `dayTokens` | 旧代码（读时滚动是新加的） |
| 聊天不涨亲密度 | `/state` 的两轮对比 | 流式记账未生效（旧模块） |

## 三、自动备份

- 目录：`~/.dsh-chubby-whale/backup/auto-*.json`；
- **首次启动会立刻备一份**，之后每小时一份，最多 7 份；
- 没有文件：看日志有没有备份相关报错（失败是静默的，但目录不存在说明 `startAutoBackup` 没跑——检查宿主是否加载了新代码）。

## 四、语音/朗读

| 症状 | 排查 |
| --- | --- |
| 完全没声 | `/tts` 返回 200 但空 → python/edge_tts 探测失败（日志 `TTS-UNAVAILABLE`）；返回 501 → 客户端应自动降级浏览器朗读 |
| 朗读卡住 | 看 `__chubbyWhale` 诊断（voices/tts 状态）；看门狗 30 秒应自动收口 |
| 念诗/说书念一半停 | 检查是否点了「停止说话」（会作废待开念）；长故事现在完整念（6000 字截断已移除） |
| 表情不显示 | `localStorage` 的 `chubby-mood-emoji` 是否为 `off` |

## 五、聊天/记忆

| 症状 | 排查 |
| --- | --- |
| 答非所问 | 先 `/clear-memory`，再 `/cache?action=clear`（导入证明数据后必须清）；或看 `/state` 亲密度是否在涨 |
| 聊完不记得 | `/personality` 看 `selfNarrative` 与口头禅是否更新（每 10 次聊天触发摘要） |
| 输入被吞 | 忙碌时输入会保留（新行为）；若还被吞，看是否点了「停止说话」把请求 abort 了 |

## 六、跨平台（Linux/macOS 真机时）

- TTS 探测顺序：`CHUBBY_WHALE_PYTHON` → `python3`/`python`（Linux/macOS）、`python`/`py -3`/`python3`（Windows）；
- 权限：POSIX 下运行目录 0700、数据文件 0600（失败静默）；
- 真机补测清单见 `docs/跨平台实测-20261106.md` 第五节。

## 七、紧急回滚

1. 客户端：直接回退 `dist/client.js`（刷新页面即换回旧版）；
2. 宿主：`git revert` 对应提交后重新构建、重启；
3. 说书进度迁移**不可逆**（旧键已移动）；若要回旧版本，需手动把 `source:书|序号` 改回 `书|序号`（保留原数据）。

> 最后一句：重启后**先跑 `/status` 与 `/stats`**，两个都 200 再谈功能。数据类问题一律先备份（导出）再动手。
