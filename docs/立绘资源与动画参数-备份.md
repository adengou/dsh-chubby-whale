## 二、旧版（横版 1696×1504）的动画参数

`src/client/anim.ts` 在提交 `ab6a2d4` 之前的样子（旧版全文已存 `Desktop\dlg\backup-data-20261106\立绘备份\anim.ts-横版立绘版本.ts`）：

```ts
// 旧版：常量是「源图坐标」，绘制时乘 sx/sy（sx=CW/1696≈0.283，sy=CH/1504≈0.283）
export const EYE_L = { x: 679, y: 430, r: 68 }
export const EYE_R = { x: 860, y: 435, r: 68 }
export const MOUTH = { x: 779, y: 525, rw: 26, rh: 18 }
const FIN_DOTS = [ {x:308,y:115}, {x:317,y:113}, {x:326,y:116}, {x:334,y:120}, {x:343,y:125}, {x:350,y:131} ]
const TAIL_TIP = { x: 391, y: 270 }   // 画布坐标（不乘 sx）
// 眨眼：每 3200 + rand*1800 ms 闭眼 150ms；drawEye 画 #F9EDE7 眼睑 + #3a2a24 眼线
// 说话嘴：drawMouth 画 #E8566B 椭圆 + #7c1f2c 内腔，尺寸 rw*1.1 / rh*1.45
```

**切换回横版的做法**：
1. 把 `whale_bak.png` 复制成 `assets/whale.png`；
2. `anim.ts` 里恢复上面第二节的 4 个常量（并让 `drawEye`/`drawMouth` 重新乘 `sx/sy`）；
3. 重新 `npm run build`，同步到 `profiles\web\node_modules\dsh-chubby-whale`。

## 三、当前版（竖版 1344×1792）的动画参数

`src/client/anim.ts`（提交 `9f7a494` 之后）——`drawImage` 按实际尺寸 contain（scale≈0.238、dx=80、dy=0），**常量是画布坐标，绘制时不乘 sx/sy**：

```ts
export const EYE_L = { x: 212, y: 111, r: 15 }
export const EYE_R = { x: 256, y: 111, r: 15 }
export const MOUTH = { x: 232, y: 126, rw: 4.2, rh: 3.4 }
const TAIL_TIP = { x: 366, y: 310 }
// 眨眼：每 3200 + rand*1800 ms 闭眼 260ms
// 说话嘴：张嘴帧露出立绘嘴；闭嘴帧用 #FDF6F0 肤色覆盖（rw*1.7 / rh*1.9）+ #C56E6A 唇线（0.3）
```

**换算依据**（竖版原图坐标 × 0.238 + 80，y × 0.238）：
- 左眼原图 (555,465) → 画布 (212,111)
- 右眼原图 (740,465) → 画布 (256,111)
- 嘴原图 (655,530) → 画布 (236,126)，实际用 (232,126)（左移 4px 对齐）
- 尾巴尖原图约 (1200,1300) → 画布 (366,310)
