## 4. 局限

1. 这是**模式扫描**，不是熵扫描/全量二进制扫描，不能保证覆盖所有自定义密钥格式；
2. GitHub/Gitee/npm 的公开缓存、fork、镜像可能保留旧对象，删除本地历史不等于清除远端缓存；
3. 文档中记载过“历史曾被重写以清密钥”，本次扫描未发现残留，但不能据此推断远端一定干净；
4. 历史扫描基于本地克隆；若远端还有未拉取的分支/tag，未覆盖。

## 5. 建议

- 若主人记得任何 Key 曾被写入仓库：**直接轮换** DeepSeek / 火山 / npm token / GitHub PAT，不要只依赖扫描结果；
- 公开仓库建议启用 GitHub secret scanning / push protection（若使用 GitHub）；
- 后续发版前，把本扫描作为发布闸门之一；
- 本报告不构成法律或安全审计意见。
