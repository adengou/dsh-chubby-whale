## 二、三个"值得一说的算法"

### 1. 流式对话 + 边生成边念（最大的体感提升）

```
旧：用户说完 → 等模型整段生成(1367ms) → 合成首段 → 开口
新：用户说完 → 模型吐第一句(698ms) → 立刻合成该句 → 开口，剩余部分边生成边念
```

- 服务端 `src/host/routes/chat-stream.ts`：SSE 转发 `delta`
- 客户端 `tryStreamChat()`：按标点切句，命中即 `speakText()`
- 任何异常 4 秒内自动回退旧 `/chat`，可用性优先
- 关掉的开关：`localStorage['chubby-stream'] = 'off'`

### 2. 统一相似度去重（`src/client/sim.ts`）

回声/重复判断原来散着四五条经验规则（完全相等、前 6 字、前 8 字、包含…），
现在统一成 **字符二元组 Jaccard 相似度**：

```ts
similarity('你好呀。', '你好呀')                       // 1.00  标点差异
similarity('天气不错你给我讲个笑话吧', '不错你给我讲个笑话吧') // 0.69  句中截断
similarity('今天天气怎么样', '讲个聊斋故事')              // 0.00  不同问句
isRepeat(..., { windowMs: 8000, threshold: 0.9 })      // 只挡 8 秒内的同句
```

### 3. 点播本地路由（省 token，也让故事完整）

```
「讲个聊斋」→ 本地《聊斋志异》原文（含"蒲松龄著"开场）  → 0 token
「为什么天是蓝的？」→ 仍走模型                            → 正常
```

根因：模型回复有 `max_tokens: 260` 上限，长故事必然被截断；本地书是一整段原文。
