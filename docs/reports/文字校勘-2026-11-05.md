## 二、特意没改的（附证据）

### 1. 说书里的「沈」1378 处 = 姓氏，不能动

```
沈琼枝、沈家、沈公、沈氏、沈约…（儒林外史、说书多本）
```

一度误改成「沉」（第 1 版脚本），已用 git 全部回退，重新按「仅诗词改」处理。

### 2. 混标点 4629 处 = 原文引号丢失，不是错字

样例：

```
三言二拍：怎见得。：清明何处不生烟？
世说新语：难乎免于今之世矣！。子无多求！
东周列国志：诸大夫可以贺我矣！。”大夫孔叔谏曰：
儒林外史：屈捐二十年来。，已是走过九省了！
```

这些都是**转录时把引号/断句弄丢**留下的叠标点，原文很可能是：

```
……怎见得？”／“……矣！”……／……二十年来，已是……
```

瞎替换会改变原文语气（例如把「。”」变成「。」就丢了对话引号），
所以只做「同一个标点重复」的合并，不同标点连用**保留原样，等原文校勘**。

## 五、如果要继续做（需主人点头）

1. **混标点规范化**：规则可定为「含 ！？→保留感叹/问号；否则含 。→保留句号；否则保留最后一个」。
   能立刻让朗读少些怪停顿，但可能把部分对话引号彻底抹掉（git 可回退）。
2. **引号重建**：需要对照原书版本逐段校勘，工作量大，不适合脚本批量做。
3. **广告垃圾二次排查**：目前只覆盖了常见几种写法，可再扫「本站」「最新章节」等词。
