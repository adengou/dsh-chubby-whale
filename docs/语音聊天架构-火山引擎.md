# 语音聊天架构设计 · 火山引擎（豆包语音）方案

> 决策：云端 TTS/ASR 主用**火山引擎豆包语音**，**按量付费**，**离线兜底**（edge-tts / 浏览器朗读）。
> 本文是**架构设计**，不含实现；接口参数以火山官方文档为准，**标「待核实」的项接入前必须逐条核对**。
> 版本参考：dsh-chubby-whale `1.1.35`。

## 一、目标与指标

| 指标 | 现状 | 目标 |
| --- | --- | --- |
| 首音频延迟 | ~2–3s（edge-tts 网络合成） | **< 1s** |
| 识别出字延迟 | ~6–15s（录满一段+上传） | **0.5–1.5s**（分段伪流式） |
| 打断 | 手动点「停止说话」 | 说话即停（阶段 3） |
| 可用性 | edge-tts 偶发 `NoAudioReceived` | 云端失败自动降级，**永不静音** |

## 二、技术前提（已确认）

- **插件 webServer 只注册 HTTP 路由**（`ctx.webServer.register({kind,path,handler})`），**没有 WebSocket**。
- 火山 ASR 的**流式接口是 WebSocket**（`wss://openspeech.bytedance.com/...`）——**插件内不可用**。
- 因此 ASR 走**HTTP 一句话识别**：客户端把录音切成 **1.5–2 秒**小段并发上传（最多 3 段在途），识别结果按序拼接 = 伪流式。
- TTS 走 **HTTP 单次合成**（文本块 → mp3 字节），客户端分块并发预取。

## 二·补充：方舟语音接口（2026-11-06 文档核实，个人版同样支持）

**鉴权**：专属 API Key（方舟「API 密钥管理」→ 开通 Agent Plan 后拿），请求头 `X-Api-Key`。

### TTS（HTTP，插件可直接调）

- `POST https://openspeech.bytedance.com/api/v3/plan/tts/unidirectional`
- 请求头：`X-Api-Key`、`X-Api-Resource-Id: seed-tts-2.0`、`Content-Type: application/json`、`X-Control-Require-Usage-Tokens-Return: *`
- 请求体：
```json
{"req_params":{"text":"要合成的文本","speaker":"zh_female_vv_uranus_bigtts","audio_params":{"format":"mp3","sample_rate":24000}}}
```
- 响应：**chunked 行流**，每行一个 JSON；`{"code":0,"data":"<base64 音频片段>"}` 累加解码即为 mp3；`code:20000000` = 结束；`code>0` = 错误。

### ASR（只有 WebSocket）

- 双流：`wss://openspeech.bytedance.com/api/v3/plan/sauc/bigmodel_async`（边说边出字）
- 单流：`wss://openspeech.bytedance.com/api/v3/plan/sauc/bigmodel_nostream`（发完音频等结果，≤15s）
- 请求头：`X-Api-Key`、`X-Api-Resource-Id: volc.seedasr.sauc.duration`
- 协议：自定义二进制帧（header + gzip JSON），**复杂但可行**。

### 关键结论（修正此前的「无 WS」判断）

- 「插件 webServer 无 WS」只限制**浏览器→插件**；**插件 host（Node）作为客户端连火山 WSS 完全可行**（用 Node 的 WebSocket 客户端）。
- 因此 ASR 也能做到「真流式」：浏览器 HTTP 分段上传 → 插件 host 用 WS 转发火山 → 结果流式回推（或分段返回）。
- **实施建议**：阶段 1 先做 TTS（纯 HTTP，立即可用）；ASR 先继续用硅基流动，等 TTS 稳定后再接火山的**单流 WS**（协议简单些），最后才考虑双流。
## 三、总体架构

```
┌──────────── 浏览器（client） ────────────┐
│ 录音（1.5–2s 段）──VAD/回声过滤（现有）    │
│   └─ POST /asr?provider=cloud  → 每段一次  │
│ 聊天 /chat-stream（现有，不变）            │
│ TTS：POST /tts?provider=cloud（分块并发）  │
│ 播放：Audio 队列（现有 ttsQ/pumpTts）       │
└───────────────┬──────────────────────────┘
                │ HTTP（插件 webServer）
┌───────────────▼──────────────────────────┐
│ host：路由层（routes/tts.ts、routes/asr.ts）│
│   provider 选择 → 端口注入                 │
├──────────────────────────────────────────┤
│ 端口层（host/ports.ts 风格，只暴露接口）    │
│   CloudTtsPort { synthesize(text,voice) } │
│   CloudAsrPort { recognize(base64,fmt) }  │
├──────────────────────────────────────────┤
│ 实现层                                    │
│   host/voice/cloud-tts.ts  → 火山 TTS HTTP │
│   host/voice/cloud-asr.ts  → 火山 ASR HTTP │
│   host/voice/usage.ts      → 日用量/预算   │
├──────────────────────────────────────────┤
│ 降级链                                    │
│   TTS：云 → edge-tts（现有 python worker）  │
│        → 浏览器 speechSynthesis（现有）     │
│   ASR：云 → 硅基流动（现有）→ 提示"听不清"  │
└──────────────────────────────────────────┘
```

## 四、配置（config.json 新增，Key 不随包分发）

```json
"cloudVoice": {
  "provider": "volcengine",          // off | volcengine | aliyun
  "tts": {
    "appId": "",
    "accessToken": "",
    "cluster": "",                   // 待核实：火山文档里的 cluster 名
    "voice": ""                      // 待核实：默认音色 ID
  },
  "asr": {
    "appId": "",
    "accessToken": "",
    "cluster": ""
  },
  "segmentMs": 2000,                 // ASR 分段长度（默认 2s）
  "maxInflight": 3,                  // 同时上传段数
  "dailyBudgetChars": 5000,          // 每日合成字数熔断
  "dailyBudgetSeconds": 1800,        // 每日识别秒数熔断
  "fallbackToLocal": true
}
```

- Key 只从本地 `config.json` 读；**导出/导入备份排除**（现有 backup 白名单机制已排除 Key）。
- 用量记 `~/.dsh-chubby-whale/cloud-usage.json`（日字数/秒数），超预算 → 自动 `provider=local`。

## 五、接口设计（插件内，不改现有契约、只加可选参数）

| 路由 | 新增 | 说明 |
| --- | --- | --- |
| `POST /tts?provider=cloud` | 可选参数 | 云端合成 mp3；失败回 edge-tts；再失败 501（客户端降级浏览器） |
| `POST /asr?provider=cloud` | 可选参数 | 云端一句话识别；失败回硅基流动；再失败 502 |
| `GET /voice/usage` | **新路由** | `{ok, dayChars, daySeconds, budget, provider}` 供诊断面板显示 |

响应/错误码沿用现有约定：业务失败 `200 {ok:false,error}`，上游不可用 501/502。

## 六、客户端改动（小）

1. `voice.ts`：合成/识别请求带 `provider`；录音段长 6s → **2s**（`segmentMs` 可配）；段并发上限 3；结果按序拼接。
2. `actions/voice.ts` 自检面板：显示 `provider`、云端用量、冷却状态。
3. 降级链不变（云端失败 → edge-tts → 浏览器）。
