# 新功能方向评估（2026-11-06）

> 本文只做**评估**，不写代码。目的：把"插件还能长成什么样"摊开，供主人挑方向。
> 每条都写了：现状、能做什么、要动哪些文件、代价与风险。

## 一、优先级建议（从省事到费事）

### A. ~~开机问候接入「今日一句」~~（**已完成，1.1.14**）
- **现状**：每日一句已有 `/daily`（本地诗库按日取，不编造），但只在菜单里点。
- **做法**：`startGreeting` 里读一次 `/daily`，进门第一句问候换成"今天这天气……哦不，今天这句诗：……"。
- **动到**：`client/effects.ts`（startGreeting）、`client/actions/content.ts`（复用已有取数）。
- **代价**：约 30 行；失败静默退回原问候。风险低。

### B. 插件设置面板可视化（**只读版已完成，1.1.18**；写配置未做）
- **现状**：数据源/人格学习/读写开关/模型名都在 `config.json` 手改，菜单里只有局部（语速/音色/开关）。
- **做法**：菜单加「设置 ▸」子菜单：数据源（本地/云端切换）、人格学习 开/关、自写 开/关、清除缓存、导出配置。
- **动到**：`client/menu.ts`（菜单项）+ `client/actions/system.ts`（动作）+ 需要一个写配置的 host 路由（**目前没有，要新增 `POST /config`**，注意不能泄露 Key）。
- **代价**：约 150 行（含新路由）；风险中（写配置错误可能让插件起不来，需严格校验 + 备份）。

### C. ~~语音唤醒词可自定义~~（**已完成，1.1.16**）
- **现状**：唤醒词写死"大肥鱼/肥鲸"（`client/wake.ts`），语音已改成"随时可以说"，唤醒词只用来剥句子开头。
- **做法**：菜单「唤醒词 ▸」列出几个候选（大肥鱼/肥鲸/小鲸/自定义输入），存 localStorage。
- **动到**：`client/wake.ts` + `client/menu.ts` + `client/actions/voice.ts`。
- **代价**：约 60 行；风险低（本地存储，即时生效）。

### D. ~~说书"连续播放"可跨书~~（**核实：已实现**）
- **现状**：一本讲完自动接下一段，讲完一本自动换下一本（可关连播）。
- **做法**：加"书单连播"（按书单顺序一本本讲），进度按书记录。
- **动到**：`host/story/player.ts`（选段逻辑）+ `client/story.ts`（连播控制）。
- **代价**：约 100 行；风险中（循环/停止语义、进度混乱）。

### E. ~~数据备份「自动定时」~~（**已完成，1.1.17**）
- **现状**：导出/导入手动。
- **做法**：host 侧每小时把 memory/personality/state 备份一份到 `~/.dsh-chubby-whale/backup/`（保留最近 7 份），菜单显示最近备份时间。
- **动到**：`index.ts` 装配 + 新 `host/backup/auto.ts`。
- **代价**：约 80 行；风险低（只读数据 + 写备份目录）。

### F. ~~插件自检面板~~（**已完成，1.1.15**）
- **现状**：`/stats` 有缓存/鱼粮/成长/亲密度/人格，但菜单里是纯文字气泡。
- **做法**：菜单「诊断 ▸」显示：数据源、模型名、TTS 引擎状态、缓存条数、上次备份时间、版本与构建时间。
- **动到**：`client/actions/system.ts` + `host/routes/stats.ts`（补字段）。
- **代价**：约 50 行；风险低。

## 二、不建议做的

| 方向 | 为什么不建议 |
| --- | --- |
| 接入在线 TTS 云服务 | 依赖外部 Key/计费，跨平台部署复杂；现有 edge-tts + 浏览器降级已够 |
| 多鱼/多角色 | 架构上单实例设计，重构成本远超收益 |
| 语音唤醒（真唤醒词检测） | 需常驻模型或云 ASR，耗电/隐私/成本都不划算；"随时可以说"已解决主要痛点 |
| 数据云端同步（账号体系） | 涉及隐私与后端成本，且当前是单机插件定位 |

## 三、与主人偏好的匹配

- 主人偏好"讲完整、有出处、不编造"——A（今日一句）与 B（设置面板）不涉及内容创作，安全；
- 主人长期用插件陪伴——C（唤醒词自定义）与 E（自动备份）提升日常体验，风险低；
- F（自检面板）对主人排障最直接。

**建议顺序**：A → F → C → E → B → D。
