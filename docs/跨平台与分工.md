## 二、无人值守规则（长期有效）

1. **不重启 dsh web**（第一原则）：只改文件、构建、测试、提交推送；生效由用户下次重启或刷新完成。
2. **只推 Gitee**：`git push origin main`（`https://gitee.com/adengou/dsh-chubby-whale`）。**不上 GitHub、不发 npm**。
3. **不向主人征求决定**：按本手册与架构宪章自行判断；拿不准时选**低风险、可回滚**的方案。
4. **每批改动必须**：`tsc` 0 错 → `esbuild` 0 错 → `node --check` → `check-imports` 0 违规 → `selftest` 通过 → `npm test` 全过；然后提交 + 推送 + 在本文档「四、批次记录」留一行。
5. **不修出新 BUG**：改动前先跑一遍基线；改完对比基线；失败立刻回退该步，不做"再试一次"式硬推。
6. **禁止越界**：分身只改分配到的模块；跨模块改动由主代理统一做。
7. **数据铁律**：不编造诗句/典故/出处；数据修复只做可证明的清理，可疑的只报告。

## 三、跨平台设计

### 目标
同一份 `dist/` 在 Windows、Linux、macOS 上都能被 DSH 加载并工作；宿主（Node）跨平台，浏览器端跨浏览器。

### 已知风险（2026-11-06 首扫）
| 风险 | 位置 | 处理原则 |
| --- | --- | --- |
| Python 解释器名（`python` vs `python3` vs `py -3`） | `host/tts-engine.ts`、`host/routes/tts.ts` | 运行时按「环境变量 → PATH 探测 → 平台默认」选择；探测失败降级浏览器朗读，不报错 |
| `spawn` 子进程细节（stdio/退出码/信号/编码） | `host/tts-engine.ts` | 统一 UTF-8、超时、退出码映射；Windows 无 SIGTERM 语义时用 kill 兜底 |
| 路径分隔与主目录 | 全仓 | 已全部用 `join` + `homedir()`（POSIX/Windows 皆可）✅ |
| 原子写 `rename` 覆盖语义 | `host/atomic.ts`、`store`、`cache` | Windows/POSIX 的 rename 均可覆盖；失败释放临时文件 |
| 文件权限 | `~/.dsh-chubby-whale/*` | POSIX 下 0600/0700，Windows 忽略；不影响功能 |
| 编码/BOM | 数据文件、spawn 输出 | 统一 UTF-8 无 BOM；读入时容错 BOM |
| 浏览器差异 | `client/voice.ts`、`client/anim.ts` | `MediaRecorder` mimeType 探测、AudioContext 前缀、speechSynthesis 可用性探测，失败降级 |

### 跨平台矩阵（验收口径）
- **宿主**：Windows 10+ / Linux（glibc）/ macOS 13+，Node ≥ 22；
- **客户端**：Chrome/Edge 最新、Firefox 最新、Safari 17+；
- 判定：`tsc`/`esbuild` 无平台相关 API 报错；无 `process.platform` 分支时功能仍可用；TTS 不可用时自动降级。
